📊 Bank Loan Analysis Power BI Project
Welcome to the Bank Loan Analysis Power BI project repository!
This project provides insightful analysis and visualizations of bank loan data, designed to support data-driven decision-making in financial institutions.

🚀 Project Overview
This Power BI solution analyzes key aspects of bank loan portfolios through three interactive dashboards:

Summary

Overview

Details

Each dashboard serves a specific analytical purpose, offering a comprehensive view into loan performance, borrower demographics, and financial trends.

🧭 Dashboards Breakdown
🔹 1. Summary Dashboard
Key Performance Indicators (KPIs):

Total Loan Applications – Track all applications received, including Month-to-Date (MTD) and Month-over-Month (MoM) changes.

Total Funded Amount – Monitor total disbursed loan amounts, with MTD and MoM comparisons.

Total Amount Received – Assess repayment performance and cash inflow (MTD and MoM).

Average Interest Rate – Calculate overall and MTD interest rates with MoM trend analysis.

Average Debt-to-Income Ratio (DTI) – Evaluate borrower risk across timeframes.

Visualization Highlights:

Loan Status Grid View – Summarizes key metrics (e.g., Funded Amount, Interest Rate, DTI) by Loan Status for quick performance snapshots.

🔹 2. Overview Dashboard
Visual exploration of broader lending trends:

Monthly Trends by Issue Date (Line Chart): Discover seasonality and lending patterns.

Regional Analysis by State (Filled Map): Pinpoint lending volume hotspots across regions.

Loan Term Distribution (Donut Chart): Breakdown by loan duration.

Employment Length (Bar Chart): Analyze loan distribution based on employment history.

Loan Purpose (Bar Chart): Categorize loans by borrower intent.

Home Ownership (Tree Map): Assess how ownership status affects loan behavior.

🔹 3. Details Dashboard
A deep-dive into individual loan and borrower metrics for granular insights:

Analyze borrower profiles, loan attributes, and repayment performance.

Supports targeted decision-making, risk management, and strategy optimization.

🗂️ Dataset Description
The analysis uses a bank loan dataset with fields including:

Loan ID

State

Loan Purpose

Grade & Subgrade

Annual Income

Loan Status

Last Payment Date

Verification Status

Debt-to-Income Ratio (DTI)

Interest Rate

These features enable assessment of borrower risk, creditworthiness, financial behavior, and overall loan portfolio health.
